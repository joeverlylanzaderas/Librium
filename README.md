# Librium: A University Library Management System

Librium is a modern University Library Management System built with **Django REST Framework** and **React Native Expo**.  
It supports book management, borrow requests, reservations, loans, fines, semesters, and role-based access for admins, librarians, and members.

---

# Features

## Authentication
- JWT Authentication
- Role-based accounts:
  - Admin
  - Librarian
  - Member
- User registration & activation

---

## Book Management
- Add / edit / delete books
- Categorize books
- Assign authors & departments
- Upload cover images
- Track availability

---

## Borrowing System
- Borrow requests
- Approval / rejection flow
- Walk-in loan support
- Return verification
- Overdue tracking

---

## Reservation System
- Reserve unavailable books
- Queue system
- Reservation notifications

---

## Fine Management
- Automatic overdue fine calculation
- Fine payment tracking

---

## Semester Tracking
- Active semester system
- Loan history per semester

---

## Dashboard
- Overview statistics
- Active loans
- Overdue books
- Pending borrow requests
- Reservation metrics
- Fine totals
